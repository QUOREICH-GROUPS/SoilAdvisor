# SoilAdvisor
Construire une application Web moderne (React + TypeScript + Tailwind) avec backend Python, Postgres/PostGIS, ingestion &amp; enrichissement satellite (NDVI, EVI), pipeline ML (classification sols, prédiction rendement, segmentation), moteur de recommandations et un LLM spécialisé (fine-tuned) pour conseils agricoles — tout en restant open-source.
